# Stayfeel — стартовый шаблон Reviews

Это начальная версия учебного проекта. В ней подготовлена верхняя часть страницы квартиры и визуальный выбор объекта. При переключении карточки обновляются данные и фотография квартиры в верхнем блоке.

Раздел отзывов, авторизация, API-запросы и CRUD-операции здесь не реализованы: студенты добавляют их самостоятельно.

## Технологии

- React 18
- TypeScript
- Vite
- Emotion для стилизации
- Axios уже добавлен в зависимости для дальнейшей работы с API

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Vite откроет проект на `http://localhost:5173`.

## Где менять данные квартир

Демонстрационные объекты и их изображения описаны в начале `src/App.tsx` в массиве `apartments`. Переключение карточек реализовано через `useState`.

## Сборка

```bash
npm run build
```
